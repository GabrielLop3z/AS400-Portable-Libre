Detrás de escena

Cómo se conecta y extrae spools

Este manual explica paso a paso cómo el sistema se conecta al mainframe AS/400, verifica las credenciales, obtiene la cola de spool y descarga el contenido de un reporte, sin usar terminales ni escribir comandos CL.

1
Inicio de sesión (crea la sesión web)
Login PHP · index.php
  1. Al enviar el formulario de login, el servidor guarda en $_SESSION['as400_session'] el usuario, contraseña e IP del mainframe que escribiste.
  2. En esta fase no se conecta aún al AS/400: la sesión queda abierta localmente.
  3. La verificación real ocurre al pedir la cola: se envía la acción verify_login a process.php.
2
Verificación y listado por el puente FTP
spool_explorer.py · FTP + RCMD
  1. process.php ejecuta src/spool_explorer.py pasándole la IP, usuario y contraseña (con list_remote).
  2. El script abre una conexión FTP (protocolo nativo de OS/400, compatible con V5R3) usando codificación latin-1.
  3. Ejecuta el comando remoto RCMD QSH CMD('system WRKSPLF ... > archivo_tmp') para volcar la lista de spool a un archivo en el IFS.
  4. Descarga ese archivo con RETR, lo decodifica y lo devuelve a la aplicación como JSON.
  5. Con esto queda validado el par usuario/contraseña: si el login falla, aquí se muestra el error de autenticación.
💡 El listado admite filtros de usuario (filter_user) y de nombre (filter_name), más paginación (limit/offset) para colas muy grandes.
3
Descarga del contenido (CPYSPLF → QTEMP)
fetch_remote · CPYSPLF + RETR
  1. Al abrir un spool, se envía fetch_remote con el file_name (y opcionalmente el número de trabajo job y SPLNBR).
  2. El puente ejecuta CPYSPLF FILE(...) TOFILE(QTEMP/...) JOB(...) SPLNBR(...) CTLCHAR(*FCFC): copia el spool a un archivo físico temporal en QTEMP.
  3. Ese archivo físico se recupera por FTP con RETR QTEMP/... y el contenido crudo se devuelve a PHP.
  4. PHP limpia las marcas de control de carro de impresora (FCFC) para obtener texto limpio y lo convierte a UTF-8 (CP850 → UTF-8).
4
Interpretación y exportación
Parser · Editor de Estructura
  1. El texto plano se envía a process.php (acción parse) donde el Parser separa cada línea y sus campos.
  2. En el Editor de Layouts defines cortes de filas y columnas para transformar el texto en una cuadrícula.
  3. Desde la barra de exportación puedes generar Excel (.xlsx/.csv) y PDF; la exportación es sanitizada para evitar inyección de fórmulas.
5
Seguridad: Usuario Puente y Gatekeeper
config/proxy.dat · config/gatekeeper.json
  • Usuario Puente (Proxy): si está configurado en config/proxy.dat (cifrado, USE_PROXY activo), el sistema conecta con ese usuario técnico y usa el usuario de la sesión como destino de listado (list_remote). Así no necesitas exponer credenciales reales.
  • Gatekeeper: el PIN maestro se almacena como hash en config/gatekeeper.json y protege la configuración del puente y la personalización de temas.
  • Sin bases de datos externas: toda la configuración vive en archivos JSON locales del servidor.
⚠️ Las credenciales del AS/400 solo viven en la sesión del navegador/servidor y se envían cifradas dentro de la sesión local. Nunca se almacenan en disco.

Paso 2

Dashboard Principal

Al ingresar verás el panel principal dividido en dos zonas: la Cola de Spools a la izquierda y la Visualización de Datos a la derecha.

Cola de Spools

Lista de todos tus archivos spool del AS/400. Muestra usuario, archivo, trabajo y número. El contador en verde indica cuántos hay en total.

Buscador Interno

Filtra la lista en tiempo real escribiendo en la barra "BUSCAR REPORTE / ARCHIVO / USUARIO...". Acepta cualquier campo de la tabla.

Sincronización

El botón Sincronizar refresca la lista desde el AS/400 al instante.

Columnas de la Cola de Spools

Columna Descripción Ejemplo
Identificación / Reporte Estado del spool (R=Ready) y nombre del archivo R · QPRTSPLF
Usuario Usuario AS/400 que generó el spool TIO21GL
Archivo Nombre del archivo de cola (spool file name) QPRTSPLF
Trabajo Nombre del trabajo que generó el reporte QPRTJOB
Número Número de trabajo dentro del AS/400 682261
NBR Número de secuencia del spool file 1, 2, 3...

Acciones Rápidas

Menú Contextual

Haz clic derecho sobre cualquier fila del spool para abrir el menú de acciones directas. No necesitas abrir el reporte primero.

Opciones disponibles

🖨 Imprimir (Quick)

Abre el reporte y lanza inmediatamente el diálogo de impresión del navegador.

📊 Excel Inteligente

Exporta el spool a un archivo Excel (.xlsx) con columnas auto-detectadas. Descarga instantánea.

📄 Texto Plano (RAW)

Descarga el spool como archivo .txt exactamente como aparece en el AS/400, sin transformaciones.

ℹ️ Propiedades Spool

Muestra la ficha completa del spool: archivo, usuario, trabajo, número, estado y páginas totales.

🧰 Gestión del Spool (sección propia)

Separador dedicado con las acciones operativas sobre el spool en el AS/400.

🔄 Reimprimir

Cambia el estado del spool a *READY para que el writer vuelva a procesarlo (CHGSPLFA STATUS(*READY)).

⏸ Mantener (Hold)

Pausa el spool con HLDSPLF. Se muestra solo si el spool no está retenido.

▶️ Soltar (Release)

Libera un spool retenido con RLSSPLF. Solo se muestra cuando el spool está en estado HLD.

⚙️ Cambiar Propiedades…

Modal CHGSPLFA: cambia estado, cola de salida (OUTQ), formulario (FORMS), copias (COPIES), prioridad (PRTY) y datos de usuario (USRDTA).

🗑 Eliminar

Ejecuta DLTSPLF con confirmación previa. Acción irreversible.

Tip: El menú se cierra automáticamente al hacer clic fuera de él. También puedes agregar usuarios a favoritos desde aquí para filtrarlos rápidamente. Las acciones en lote (Mantener / Soltar / Eliminar) están disponibles en la barra flotante al seleccionar varios spools con las casillas.

Función Avanzada

Editor de Layouts

El Mapeador de Layout te permite definir con precisión milimétrica cómo se separan las columnas del reporte para una exportación Excel perfecta. Imprescindible para reportes de columnas fijas.

Cómo usar el editor

1
Abre el reporte

Haz clic sobre cualquier fila del spool para cargarlo en el panel de visualización.

2
Presiona el botón EDITOR

Ubicado en la barra superior del panel derecho, abre el Mapeador de Layout en pantalla completa.

3
Haz clic para trazar divisorias

Haz clic en el visor del reporte para colocar líneas de corte verticales (COLUMNAS) u horizontales (FILAS). Cada línea define el límite de una columna en Excel.

4
Exporta a Excel

Con las divisorias definidas, presiona TXT o EXCEL en la barra inferior. El sistema divide el spool según tu mapa.

Controles del editor

|
COLUMNAS

Modo para trazar cortes verticales. Separa el reporte en columnas de izquierda a derecha.

—
FILAS

Modo para trazar cortes horizontales. Útil para omitir encabezados o pie de página.

✕
LIMPIAR

Elimina todas las divisorias trazadas para empezar de nuevo.

±
AJUSTE VISUAL − / +

Cambia el tamaño de fuente del visor del editor para ver mejor los datos sin afectar el corte.

💡 Pro Tip

El indicador BANDAS: X | CORTES TOTALES: Y en la esquina inferior izquierda te muestra cuántas divisorias has definido en tiempo real.

Exportación

Exportar y Guardar PDF

Exporta cualquier reporte a Excel, TXT o PDF. Puedes hacerlo de forma individual o en masa con múltiples spools seleccionados.

Exportación Individual

EXCEL

Botón EXCEL en la barra superior derecha. Exporta el spool activo a un archivo .xlsx con columnas inteligentes.

→ Descarga automática al navegador
TEXTO

Botón TEXTO en la barra superior. Descarga el spool como archivo .txt en formato RAW exacto del AS/400.

→ Archivo .txt con saltos de línea originales
PDF / IMPRIMIR

Ícono de impresora (cian, esquina superior derecha del panel). Abre el diálogo nativo del navegador para imprimir o guardar como PDF.

→ Seleccionar "Guardar como PDF" en el navegador
🖨 Cómo guardar como PDF
1 Haz clic en el ícono de impresora (botón cian en la esquina superior derecha del panel de reporte)
2 El sistema prepara el formato AS/400 en alta resolución (puede tardar 1-2 seg)
3 Se abre el diálogo de impresión del navegador
4 En Destino / Impresora, selecciona Guardar como PDF
5 Elige la ubicación y guarda. El PDF mantiene la fuente monoespaciada del mainframe.

Mantenimiento

Actualizaciones

La aplicación se actualiza a nuevas versiones directamente desde el panel. El botón Actualizar de la barra lateral abre el centro de actualizaciones para buscar, instalar o revertir versiones.

Cómo funciona

📥 Buscar actualizaciones

Consulta el repositorio y muestra la versión remota, la fecha de la última comprobación y el changelog de la nueva versión.

⬆ Instalar

Descarga el paquete oficial, verifica su firma SHA-256, comprueba que el código no tenga errores de sintaxis y aplica los cambios creando un respaldo automático en la carpeta backups/. Tus datos de usuario (configuración, proxy, uploads y exportaciones) se conservan.

↩ Revertir

Restaura la versión anterior desde el último respaldo de actualización si algo no funciona como esperabas.

🔐 Seguridad

Las acciones de instalar, revertir y guardar configuración requieren la contraseña de administrador (Gatekeeper) si está activada.

Usuarios Favoritos

Favoritos y Filtrado Rápido

Guarda usuarios de AS/400 como Favoritos para filtrar sus reportes con un solo clic desde el buscador. Ideal cuando hay múltiples usuarios en el sistema y necesitas ver solo los de tu área.

Cómo agregar un usuario a Favoritos

1
Localiza la estrella ★

En la barra de pestañas (parte superior), cada usuario activo tiene una estrella ★ a la derecha de su nombre. También aparece en el sidebar junto a su perfil.

2
Haz clic en la estrella

Un clic en la ★ agrega el usuario a tu lista de favoritos. La estrella cambia de color para confirmar. El usuario queda guardado en el navegador.

3
También desde el menú contextual

Haz clic derecho sobre cualquier fila del spool → el menú contextual puede incluir la opción de agregar el usuario de esa fila a favoritos directamente.

💡 ¿Dónde se guardan?

Los favoritos se guardan en el localStorage del navegador y en el Centro de Control. Son persistentes entre sesiones mientras uses el mismo navegador y máquina.

Filtrado Rápido desde el Dropdown

Al hacer clic en el tab de usuario (la pestaña que muestra el nombre en la barra superior), se despliega un menú con todos tus usuarios favoritos para acceso instantáneo.

Gestión de Favoritos — Importar y Exportar

Desde el Centro de Control (ícono ⚙ en el sidebar) puedes administrar tu lista completa de favoritos.

👁️ Ver spools

El ícono de ojo junto a cada usuario favorito filtra la cola de spools directamente sin cerrar el modal.

🗑️ Eliminar favorito

El ícono de papelera junto a cada usuario lo elimina de la lista de favoritos permanentemente.

⬆ IMPORTAR

Carga una lista de favoritos desde un archivo JSON exportado previamente. Útil para compartir la misma configuración entre máquinas o usuarios del equipo.

→ Selecciona el archivo .json cuando te lo pida el navegador
⬇ EXPORTAR

Descarga tu lista de favoritos como archivo JSON. Guárdalo para hacer un respaldo o para importarlo en otra PC con la misma versión de SPOOL Engine.

→ Descarga automática: favoritos.json
